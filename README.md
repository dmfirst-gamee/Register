# DMFirst Game Guide

SEO-focused static website for DMFirst-related informational guides.

## Deploy with Netlify
1. Connect this GitHub repository to Netlify.
2. Set the publish directory to `.`.
3. Set `SITE_URL` to your final HTTPS custom domain before deploying so canonical URLs and sitemap entries use the correct domain.
4. Submit `/sitemap.xml` in Google Search Console after deployment.

The site is informational and is not represented as the official DMFirst platform. Verify platform-specific terms and local rules independently.
